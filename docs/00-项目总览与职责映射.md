# 00 · 项目总览与职责映射

> 本文档回答两个问题：母项目"平台治理智能体"的整体流程与 Agent 设计是什么？
> 马珠淇负责的"产品与技术方案"在其中处于什么位置、如何映射到本仓库？

## 1. 母项目全景

**项目**：面向用户的平台治理支持智能体系统设计与实践（中国人民大学 2026 大创，负责人纪力宁）

**问题背景**：数字平台规则复杂且碎片化，用户面对虚假宣传、软广暗广、交易纠纷时处于信息劣势；
央视 3·15 晚会《谁在给 AI"投毒"》进一步曝光了 GEO 灰黑产——通过批量铺设"软文/榜单/测评"
内容网络，让联网检索型 AI 的回答被伪造"证据链"牵引，从而操控用户的决策入口。

**治理模式创新**：从"平台侧中心化治理"转向"用户侧去中心化赋能"——让 AI 站在用户一边，
像第三方审计师一样主动提示风险、引导调查、辅助维权。

## 2. 系统总体架构（三大工作流 × 两级防御）

### 2.1 三大核心工作流

│         ┌────────────────┴────────────────┐                      │

│   · LLM 综合推理                     推荐引擎层:                      │

### 2.2 GEO 投毒检测：端侧 + 云侧两级联动防御

- **端侧（浏览器插件，300–800ms）**：正文/元数据/外链/资源指纹采集 → AIGC 概率评估、
  高风险话术匹配、提示注入扫描、Stylometry 风格一致性 → 域名年龄/SSL 证书簇/脚本复用等
  基础设施取证；只上传哈希化极小特征集（隐私最小化）。
- **云侧（Agent 大模型深度研判）**：外部搜索与情报库补齐证据 → 页面-域名-作者-评论
  异构图谱 → GraphSAGE/GCN 对链接农场、协同发布、内容复用等"投毒集群行为"建模 →
  结果反哺端侧规则与轻量模型，形成闭环演进。
- **四模块流水线**：数据采集与标准化（Evidence Bundle）→ 基于对抗理论的特征提取（四通道）
  → 联邦建模与风险融合（规则兜底 + 模型集成 + 概率校准，SHAP/IG/GNNExplainer 可解释）
  → 在线评估与决策支持（高=阻断并剔除引用源+Re-Prompt / 中=多源交叉验证+标注不确定 /
  低=通过并记录，反馈闭环）。
- **数据基础**：自建 GEO 数据集——40 个核心商品品类、5000+ URL、400+ 组针对性提问与
  AI 反馈标注；已归纳出"专业词汇滥用、语义结构高度对齐"等 GEO 操纵典型特征。

## 3. 马珠淇职责域 → 本仓库映射

**职责**：产品与技术方案——智能体功能与技术方案设计，覆盖
GEO 逆向甄别、虚假宣传识别、数据筛查与标注机制、长期记忆、用户画像、多轮交互、行动引导。

| # | 职责 | 在母项目中的位置 | 本仓库交付 |
|---|---|---|---|
| 1 | GEO 逆向甄别 | 反 GEO 投毒模块（端云两级的知识与判定核心） | RAG 设计文档 + `geo_guard` 完整实现 |
| 2 | 虚假宣传识别 | 工作流一的 AI 分析层与决策判定层 | 三条鉴别路径方案 + `detection/` 实现 |
| 3 | 数据筛查与标注机制 | 数据与标注流水线（三层数据：样本池/白名单/对抗集） | 标注 schema + `ingest.py` 管线 |
| 4 | 长期记忆 | 记忆管理层（情景记忆+语义记忆，衰减与整合） | `memory.py`（SQLite+向量+衰减） |
| 5 | 用户画像 | 画像构建层（动态状态向量：风险规避/价格敏感/品牌导向） | `memory.py` 画像模块 + 检索权重联动 |
| 6 | 多轮交互 | 交互控制层（状态机+主动询问触发器） | `dialogue.py` 状态机实现 |
| 7 | 行动引导 | 任务规划层（行动链 DAG、给证据+给路径+帮执行） | `dialogue.py` DAG + `plugin.py` 工具 |

**落地形态**（对应母项目"网页插件 + 完整智能体等多种形态"的规划）：

1. **Agent 插件**：`geo_guard.plugin.GeoGuardPlugin` 以工具集形式挂载到任意 function-calling LLM Agent；
2. **Personal Agent**：`geo_guard.agent.PersonalAgent` 独立 CLI 多轮智能体，无 API 降级规则驱动。

## 4. 关键既有约束（来自母项目文档，本仓库继承）

1. 话术与骗术知识库相似度 **> 70% 触发警告**（继承为"单一强信号"，但等级判定必须多信号融合）；
2. **三档风险决策**：高=阻断/剔除引用源，中=提示+多源交叉验证，低=通过+记录；
3. **仅靠 AIGC 检测远远不够**（可被对抗性改写削弱）→ 一切单信号只做弱证据入融合；
4. 判定必须**可解释**：给结论更要给证据链（话术片段、匹配模式、权威对照、博主历史）；
5. 隐私最小化：端侧本地处理优先，上传仅限哈希化特征；
6. 防御视角抽象：不提供任何可操作的投毒步骤。
