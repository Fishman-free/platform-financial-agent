# 04 · 数据筛查与标注机制

> 对应母项目"数据与标注流水线"阶段（3–6 周并行工期）与三层数据战略
> （真实样本池 / 可信白名单对照集 / 合成对抗集）。代码落点：`geo_guard/ingest.py`。

## 1. 管线总览

```text
采集(爬取/团队语料/用户提交)
  → ① 清洗与标准化(Evidence Bundle 化)
  → ② 去重(simhash, 保留复用计数)
  → ③ 弱标签(规则+白名单)
  → ④ 人工复核队列(按不确定度排序)
  → ⑤ 入库(KB 版本化写入, source 强制)
  → ⑥ 反馈闭环(用户异议/申诉 → 回到④)
```

## 2. 各环节设计

### ① 清洗与标准化

统一为 Evidence Bundle：`{url?, text, title?, author?, published_at?, domain_meta?, comments[]?}`。
多模态上游（OCR/ASR/VLM）的产出也归一到该结构，管线不感知来源形态。

### ② 去重（I-23 修订版）

- simhash 64bit（中文字符 bigram 加权），海明距离 ≤ 3 判近重复；
- **关键设计**：近重复不直接丢弃——跨站复用本身是投毒信号，去重时把
  `reuse_count` 与 `reuse_domains[]` 累加到代表条目上，作为 F4/F6 的输入特征；
- 同域内重复（转载/分页）只计数不计域。

### ③ 弱标签（I-22）

| 规则 | 伪标签 | 置信 |
|---|---|---|
| L1 注入模式命中 | GEO投毒 | 高 |
| KB1 话术 ≥0.70 且事实核验 contradicted | GEO投毒 | 中 |
| 白名单域名（政府/权威媒体/行业协会/国标库） | 良性锚点 | 中（白名单≠免检，评论区块单独过） |
| 仅话术命中、事实无矛盾 | 可疑营销 | 低 |
| 其余 | 未定 | — |

### ④ 人工复核队列

- 排序键：模型不确定度（|score−阈值| 升序）优先，其次 severity 加权；
- 标注界面最小字段集（见 §3 schema）；双人背靠背标注，分歧仲裁制；
- 标注指南必须含**判例对**（投毒 vs 正常营销的边界案例，对抗评审 #7）。

### ⑤ 入库治理（I-12/I-25）

- `source` 与 `checked_at` 强制非空，否则拒绝写入；
- 条目写入即产生新版本号，旧版本置 deprecated 不删除（可回滚可审计）；
- 批量入库需二人复核（团队流程，代码层以 `pending_review` 状态隔离未复核条目——
  该状态条目不参与线上判定）。

### ⑥ 反馈闭环（I-26/I-30）

- 用户对判定的"认同/异议"写入 feedback 表；异议自动进复核队列；
- 周度聚合：同一模式被异议 ≥ N 次 → 触发该 KB1 条目的人工复审（可能是误伤模式）；
- 复核结论回写：更新模式条目 / 调整阈值锚点 / 修正标注指南。

## 3. 标注 Schema（I-21）

```jsonc
{
  "sample_id": "s-000123",
  "label": "geo_poisoning | suspicious_marketing | benign",
  "evidence_spans": [                       // 证据定位，训练与解释两用
    {"start": 120, "end": 187, "pattern": "ranking_template", "note": "无方法论榜单"}
  ],
  "pattern_tags": ["ai_citation_bait"],     // KB1 category 多选
  "claims": [                               // 事实性声明标注（路径一用）
    {"text": "7天美白", "verdict": "contradicted", "ref": "kb3-fact-0012"}
  ],
  "annotator": "A01", "reviewer": "A02",    // 双盲+仲裁
  "agreement": "final | disputed",
  "guideline_version": "1.2"
}
```

## 4. 合成对抗集（I-10，红线约束）

- 三类变体：同义改写（LLM 对已判定样本 paraphrase）、体裁迁移（榜单→测评→问答）、
  模板换壳（更换品牌词与域名的同构文本）；
- **仅内部评测**，存储于隔离目录，不入检索库、不外发、不用于任何面向用户的输出；
- 用途：检出衰减曲线（对抗鲁棒性专项指标，对齐母项目评估计划）。

## 5. 与团队既有数据的对接

母项目已有：40 品类 / 5000+ URL 的 GEO 数据集、400+ 组提问与 AI 反馈标注。对接方式：

1. URL 清单 → 采集层批量抓取 → 走本管线 ①~④；
2. 400 组标注作为**阈值锚点集**（对抗评审 #4）：观察 risk_score 分布，人工定 T_high/T_low 初值；
3. 已归纳特征（专业词汇滥用、语义结构高度对齐）已固化进 KB2 与 features.py 检测器。
