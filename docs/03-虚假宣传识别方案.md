# 03 · 虚假宣传识别方案

> 对应母项目"工作流一：虚假宣传鉴别"的 AI 分析层与决策判定层。
> 核心思路：三条鉴别路径全部落到 GEO 甄别内核的证据管线上（复用而非另建）。

## 1. 三条鉴别路径 → 内核映射

母项目需求（原始文档）规定了三种鉴别方式，本方案给出实现映射：

### 路径一：权威文件核验（购物/旅游场景）

- **购物平台**：读取说明书与成分表（上游多模态层 OCR 产出），抽取事实性声明
  （功效/成分/资质/适用范围），与 **KB3 权威事实库** 比对：
  - 保健食品声称治疗功能 → contradicted（《广告法》第十八条）；
  - 化妆品宣称医疗功效 → contradicted（《化妆品监督管理条例》）；
  - 无批准文号却声称"国食健字" → contradicted；
  - 无法核验的量化声明（"7 天见效"）→ unverified，计入事实信号。
- **旅游平台**：路线商业化程度、购物点安排 → 检索 KB4 案例库（游客反馈判例）
  + 实时搜索接口（预留），输出"雷点列举"。
- 代码落点：`geo_guard/detection/claims.py`（claim 抽取与三态核验）。

### 路径二：话术相似度告警（>70% 阈值）

- 内容按句/段切分为证据单元，与 **KB1 话术模式库** 做混合检索；
- 相似度 ≥ 0.70 → 高危话术信号（强证据），0.50~0.70 → 弱证据；
- 每个命中记录：模式名、类别、相似度、原文片段定位、法条映射 → 直接进证据链卡片。
- 代码落点：`geo_guard/detection/patterns.py`。

### 路径三：评论区有效性筛选

- 上游爬取评论（接口预留），本层负责**有效性筛选**：
  - 水军特征：文本近重复（simhash 距离）、账号名模式、时间聚簇（同分钟爆发）；
  - 广告特征：命中 KB1 话术模式的"正向评论"反向计为可疑（好评刷单信号）；
  - 有效负评：情感极性 + 具体性（含商品属性词的负面描述权重高）。
- 输出：负面占比、高频雷点词、可疑水军比例 → 进 F4 来源信号与证据链。
- 代码落点：`geo_guard/detection/features.py` 的评论子通道（当前以离线评论列表为输入）。

## 2. 博主信用背书

```text
credit_score = 0.4×历史推广频率分 + 0.3×违规/翻车记录分 + 0.3×内容一致性分
```

- 数据载体：KB4 案例库 `case_type=influencer_record`；
- 冷启动：无档案博主 → credit=0.5（中性），输出标注"该博主暂无信用记录"；
- 与 GEO 检测的关系：博主信用是 F4 来源可信度的子分量，不单独定档。

## 3. 决策与输出

三路径证据统一进入 `fusion.py` 三层判定（见 docs/02 第 5 节），输出差异化处置：

| 档位 | 输出内容 |
|---|---|
| 高风险警告 | 判定理由 + 证据来源（话术片段/矛盾事实/负面评论摘要/博主记录）+ 维权建议（KB5） |
| 中风险提醒 | 注意事项清单 + 建议核实项 + 主动质询（"需要我检索该产品的历史差评吗？"） |
| 安全确认 | 可信度依据 + 置信说明（避免"绝对安全"表述——判定是风险提示不是担保） |

## 4. 防误伤设计（对抗评审 #7 决议）

正常商业营销与虚假宣传的区分不靠"出现了营销词"，而靠三信号共振：

1. 话术命中操纵性模式（而非一般推广用语）；
2. 事实核验出现 contradicted/unverified 聚集；
3. 来源可疑（无信用记录 + 非白名单 + 结构特征异常）。

只有营销话术、但事实可核验且来源可信的内容 → 最多 LOW~MEDIUM，且证据链明示
"属正常商业推广，未发现虚假宣传证据"。
