# Spec Delta

## Purpose

提供 GEO 逆向甄别的知识底座：五类知识库的统一存储与治理，以及混合检索管线，
保证任何判定证据都能溯源到具体知识条目，且在无外部服务时仍可离线运行。

## ADDED Requirements

### Requirement: 五库分治的知识库存储
系统 SHALL 维护五个独立知识库：话术模式库、GEO 结构特征库、权威事实库、
历史案例库、平台规则库；所有条目 MUST 共用统一信封字段
（entry_id、kb、title、content、severity、category、metadata、source、
version、checked_at、status）。

#### Scenario: 种子知识库构建
- **WHEN** 首次运行知识库构建且本地无任何数据
- **THEN** 系统从种子语料创建五库，条目总数 > 0，且每个库至少含 3 条 active 条目

#### Scenario: 重复构建幂等
- **WHEN** 对同一版本种子语料重复执行构建
- **THEN** 已存在的同 entry_id 条目不重复插入，知识库总条目数不变

### Requirement: 条目治理强制约束
系统 MUST 拒绝 source 为空的条目入库；status 为 pending_review 的条目
MUST NOT 参与线上判定检索；条目更新 MUST 产生新版本且旧版本可查（不物理删除）。

#### Scenario: 无来源条目被拒绝
- **WHEN** 提交一条 source 为空的知识条目
- **THEN** 入库失败并返回明确的缺失字段错误，知识库内容不变

#### Scenario: 待复核条目不参与判定
- **WHEN** 检索请求命中一条 status=pending_review 的条目
- **THEN** 该条目不出现在判定用检索结果中

### Requirement: 混合检索与融合排序
检索 SHALL 同时执行稀疏通道（中文字符 bigram BM25）与稠密通道（向量余弦），
并以 RRF 融合排名；检索 MUST 支持按库别、类别、适用品类、状态做元数据前置过滤。

#### Scenario: 话术模板的字面召回
- **WHEN** 以话术模式库中某条目的触发例句（或其高重合变体）作为查询
- **THEN** 该条目出现在 top-5 检索结果中

#### Scenario: 库别过滤生效
- **WHEN** 检索指定仅查询平台规则库
- **THEN** 返回结果中不包含其他四库的条目

### Requirement: 嵌入后端可插拔与离线兜底
系统 SHALL 支持至少两种嵌入后端：本地确定性哈希嵌入（零外部依赖）与
云端 API 嵌入（OpenAI 兼容协议）；未配置任何 API 密钥时 MUST 自动使用
本地后端并保证全链路可用，且输出中声明当前为降级嵌入模式。

#### Scenario: 无密钥离线运行
- **WHEN** 环境中不存在任何 LLM/嵌入 API 密钥
- **THEN** 知识库构建与检索正常完成，系统输出标注本地嵌入降级状态

#### Scenario: 阈值随后端校准
- **WHEN** 使用本地哈希嵌入后端执行话术相似度匹配
- **THEN** 高危话术触发阈值相对云端嵌入自动下调固定偏移量（默认 0.05），
  且该偏移量可配置

### Requirement: 相似度分级语义
话术匹配 SHALL 输出 0~1 相似度并分级：≥0.70 为高危话术信号（强证据），
0.50~0.70 为弱证据，<0.50 不产出证据；高危话术信号 MUST NOT 单独决定
最终风险等级（单信号禁否决原则）。

#### Scenario: 强证据不单独定罪
- **WHEN** 一段文本仅命中一条高危话术模式，其余全部通道无风险信号
- **THEN** 最终判定不高于 MEDIUM，且证据链标注"单一信号，建议交叉验证"

### Requirement: 检索性能与规模边界
本地知识库在 5 万条目规模内，单次混合检索（不含 LLM 重排）P95 延迟
SHALL 低于 1 秒（普通笔记本环境）。

#### Scenario: 千级种子库检索延迟
- **WHEN** 在种子知识库（千级条目以内）上执行单查询混合检索
- **THEN** 返回时间 < 1 秒
